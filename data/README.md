# Data

The audited R Markdown source downloads the two public course files into this directory when they are not already present:

- `pml-training.csv`
- `pml-testing.csv`

Source: the Weight Lifting Exercise Dataset used in the Practical Machine Learning course.

The CSV files are intentionally not committed here. Feature filtering is derived from the labelled training file only and the identical predictor names are then applied to the quiz/test file.
